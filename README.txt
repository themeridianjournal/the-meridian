THE MERIDIAN
Understanding Power. Explaining the World.
=============================================

HOW TO VIEW THE WEBSITE
-----------------------
On an ANDROID PHONE OR TABLET:
  Open "preview-android.html". It contains the whole website in one file,
  so it works when opened from the Files app.
  (Opening "index.html" from the Files app shows a plain, unstyled page,
  because Android only lets Chrome read that one file, not style.css or
  script.js next to it.)

On a WINDOWS COMPUTER:
  Extract the ZIP first, then double-click "index.html".

On the INTERNET (GitHub Pages):
  "index.html" works everywhere once the site is uploaded.

An internet connection is needed for the fonts to look right.


WHAT EACH FILE DOES
-------------------
index.html     The homepage.
category.html  The section pages (Indian Politics, Geopolitics, etc.).
               One file shows every section.
article.html   The article pages. One file shows every article.
404.html       The "page not found" page. GitHub Pages uses it automatically.
style.css      The look of every page: colours, fonts, spacing, layout.
script.js      The behaviour: phone menu, date, newsletter form,
               the list of all articles, and the illustrations.
preview-android.html  The whole site in ONE file, for viewing on Android.
               Not needed on GitHub Pages (but harmless to upload).
README.txt     This note.

Keep all of these files together in the same folder.
Do not rename them, because the pages link to each other by name.


IMPORTANT NOTES
---------------
- The articles are SAMPLES with placeholder text. Real articles come later.
- The illustrations are drawn by code, so there are no image files to lose.
  They can be replaced with real photographs later.
- The newsletter form checks the email address but does not send anything
  yet. A free newsletter service can be connected later.
- The site is ready for free hosting on GitHub Pages: upload all the files
  in this folder (not the folder itself) to a GitHub repository.
